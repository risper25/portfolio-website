# Risper Bevalyn portfolio

A responsive portfolio built with plain HTML, CSS, and JavaScript for GitHub Pages. No build
step, server-side code, or package installation is required.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server.

## Assets and content

- `images/risper-bevalyn.jpg` is the profile portrait.
- `assets/risper-bevalyn-cv.pdf` is the downloadable CV.
- Edit the profile, project details, experience, skills, education, and contact links in `index.html`.
- Adjust the color tokens, typography, and responsive layouts in `styles.css`.
