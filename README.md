# Risper Bevalyn portfolio

A responsive portfolio site built with plain HTML, CSS, and JavaScript. No build step or
package installation is required.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server.

## Update your portfolio

- Edit your profile, experience, selected work, skills, education, and contact links in `index.html`.
- Adjust colors, typography, and layouts in `styles.css`.
- Replace the CSS artwork in the profile and project cards with your own images if desired.
